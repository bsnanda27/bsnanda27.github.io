PROJECT NOTE / 01

DIGITAL HARDWARE · VISION TRANSFORMERS

TokenFold.

Selecting what matters.
Understanding the cost of moving it.

TokenFold explores hardware support for token selection and compaction in Vision Transformer workloads. The project connects a software-level reference with RTL development, streaming data movement and system-level verification.

01 / SCORE02 / SELECT03 / COMPACT04 / COMPUTE
A / PURPOSE

Work before computation

Vision Transformer workloads process sequences of tokens. TokenFold explores selecting useful tokens and compacting their embedding rows before downstream computation.

B / DATA MOVEMENT

Keep the sequence coherent

Selection must preserve the association between a retained embedding row and its original token. Streaming interfaces connect this behavior to the surrounding system.

C / VERIFICATION

Reference to RTL

The software reference gives a behavioral baseline. RTL and system simulation help examine whether selection, transfer and control remain consistent together.

D / DESIGN QUESTION

Account for overhead

Reducing the token count is only one part of the problem. The time spent selecting and moving data must be considered alongside the computation it saves.

This overview presents the project's purpose and engineering questions; performance figures are omitted until they can be shared with supporting measurements.

PROJECT NOTE / 02

PROCESSOR DESIGN · RISC-V

RV32I processor.

From instruction behavior
to synthesized hardware.

A processor built from scratch around the RISC-V RV32I instruction set. The work follows the design from architectural behavior into RTL, then through simulation and synthesis.

01 / FETCH02 / DECODE03 / EXECUTE04 / UPDATE
A / ARCHITECTURE

An instruction becomes behavior

The RV32I base integer instruction set defines the visible behavior of the processor. Instructions connect register operations, arithmetic, memory access and program control.

B / IMPLEMENTATION

Datapath and control

Register values, immediate values and arithmetic logic form the datapath. Control decisions coordinate how these pieces implement each instruction.

C / SIMULATION

Follow the state

Testbenches, instruction traces and waveform debugging provide ways to inspect register updates, memory operations and changes to the program counter.

D / SYNTHESIS

From RTL to logic

Synthesis connects the RTL description to a logic implementation. The resulting structure and timing reports make the consequences of design choices easier to study.
